2026-09-29のJS: React 19.3、pnpmのPython/Cargo対応、Vite+ 1.0

2026年09月29日 Edit on GitHub 編集履歴を見る
  • Tweet

JSer.info #780 - React 19.3がリリースされました。

  • React 19.3 – React

<ViewTransition>とFragment RefsがStableになりました。
react-domに、use(browser())でコンポーネントをブラウザでのみ描画するためのbrowser()が追加され、Trusted Types APIに対応しています。
Server Componentsで<Context>を直接レンダリングできるようになり、onFullscreenChange/maskTypeのサポートなども追加されています。

pnpm 12.4、12.6がリリースされました。

  • pnpm 12.4 | pnpm
  • pnpm 12.6 | pnpm

pnpm 12.4では、python.enabled/cargo.enabledによるPython/Cargoの依存関係管理に対応しています。
Cargo対応の背景には、Rustで書かれるようになったpnpm自身の依存関係をpnpmで解決したいという開発者の意図があります。
また、pnpm pipeline、trustPolicyExcludePrune、pnpm change checkが追加されています。

pnpm 12.6では、autoDedupeによる依存関係の重複排除、pnpm add --save-types、Catalogsでのfile:/link:のサポートが追加されています。
このほか、pnpm tasks status、pnpm cache prune --dry-runが追加されています。

Vite+ 1.0がリリースされました。

  • Announcing Vite+ 1.0 | VoidZero

Betaからは、GitLab CI/CD向けのsetup-vp、HomebrewとDockerイメージ、vp hooks/vp stagedなどが追加されています。
vp testとvite-plus/test*がVitest 5.0.1へ移行し、CLIのNode.jsサポート範囲が変更されています。
oxlint/oxfmtの実行ファイルラッパーが削除され、vp lint --lsp/vp fmt --lspを使う形に変更されています。
また、vp migrateによるVitest 5への移行、npm provenance検証、vp add --offline/--frozen-lockfileのサポートなどが追加されています。
