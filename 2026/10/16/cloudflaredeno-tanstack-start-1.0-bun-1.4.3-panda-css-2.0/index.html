2026-10-16のJS: CloudflareがDenoを買収、TanStack Start 1.0、Bun 1.4.3、Panda CSS 2.0

JSer.info #781 - CloudflareによるDenoの買収が発表されました。

  • Deno is joining Cloudflare | Deno
  • The state of Deno after the Cloudflare announcement · Issue #37030 · denoland/deno

Denoランタイムは1年間の不具合修正・セキュリティ更新を行った後、Denoチームによる開発を終了するとしています。
Deno Deployは6か月後に終了し、JSRはCloudflareへ移行して継続するとしています。
今後はWorkersとDurable Objectsのプラットフォームに注力し、rusty_v8は引き続きサポートしてworkerdへの統合を進める予定としています。

TanStack Start 1.0がリリースされました。

  • TanStack Start 1.0 is Stable | TanStack Blog

TanStack Startは、TanStack Routerを基盤とするReact/Solid向けのフルスタックフレームワークです。
SSRとストリーミング、型付きサーバ関数のcreateServerFn、実行環境ごとに処理を切り替えるcreateIsomorphicFnを提供しています。

Bun 1.4.3がリリースされました。

  • Bun v1.4.3 | Bun Blog

TypeScriptの型チェックを行うbun checkが追加され、bun run --check/bun test --check/bun build --checkに対応しています。
また、--disallow-code-generation-from-stringsによる文字列からのコード生成の禁止、bun build --compile --bytecode-orderに対応しています。

Panda CSS 2.0がリリースされました。

  • Panda CSS 2.0 | Panda CSS Blog - Panda CSS

Panda CSS 2.0では、ESMのみとなりNode.js 22以上が必要になり、hooksがpluginsへ移動しています。
また、コンパイラがRustとOxcで書き直され、panda libとdesignSystemによるデザインシステムの配布に対応しています。
そのほか、viewTransition()/firstThatWorks()/keyframes()/positionTry()、panda doctor/panda analyze/panda debugが追加されています。
