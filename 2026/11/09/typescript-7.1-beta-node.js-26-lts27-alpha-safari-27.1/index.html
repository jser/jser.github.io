2026-11-09のJS: TypeScript 7.1 Beta、Node.js 26 LTS/27 Alpha、Safari 27.1

JSer.info #782 - TypeScript 7.1 Betaがリリースされました。

  • Announcing TypeScript 7.1 Beta - TypeScript

Ambient ModulesでのImport Attributes、import source/import.source()に対応しています。
--target es2026/--lib es2026が追加され、Promise.allKeyedなどの型定義も追加されています。
また、typescript/sync/typescript/asyncなどの新しいAPI、埋め込みコードを扱うContent Mappersが追加されています。

Node.js 26.13.0がリリースされ、Node.js 26系がコードネームLithiumとしてLTSに移行しました。

  • Node.js — Node.js 26.13.0 (LTS)

Node.js 26系は2029年4月末までサポートされます。
Node.js 25以降のLinux公式バイナリはlibatomicにリンクされており、古いLTSからの更新時には別途インストールが必要になる場合があります。

また、Node.js 27 Alphaがリリースされました。

  • Node.js — Node.js 27.0.0-alpha.0.0.0 (Alpha)

Node.js 27からは、リリーススケジュールが変更されています。
メジャーリリースは年2回から年1回となり、奇数・偶数の区別なく各メジャーバージョンがLTSへ移行します。
6か月のAlpha、6か月のCurrentを経て、30か月のLTSとしてサポートされます。
Node.js 27は、2027年4月にCurrent、同年10月にLTSへ移行する予定です。

V8 15.6へアップデートされ、Math.sumPrecise()/Iterator.zip()などに対応しています。
破壊的変更として、ヒープ上限の既定値が変更されています。
Buffer/ArrayBufferのメモリもヒープ上限に算入されます。
v8.serialize()の出力形式が変更され、旧バージョンでは読み込めなくなっています。
このほか、node:vfsのフラグが不要になり、環境変数へのアクセスを制御する--allow-env、実験的なnet/promises APIが追加されています。

Safari 27.1がリリースされました。

  • WebKit Features for Safari 27.1 | WebKit

iPhone Duo向けにDevice Posture APIとViewport Segments APIを、機能フラグ付きで試験的にサポートしています。
device-postureメディアクエリやnavigator.devicePostureで折りたたみ状態を取得できます。
また、window.viewport.segmentsやCSS環境変数で画面の分割領域を取得できます。
