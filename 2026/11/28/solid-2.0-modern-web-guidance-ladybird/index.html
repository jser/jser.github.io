2026-11-28のJS: Solid 2.0、Modern Web Guidance、Ladybirdアルファ版

2026年11月28日 Edit on GitHub 編集履歴を見る
  • Tweet

JSer.info #783 - Solid 2.0がリリースされました。

  • Solid 2.0 - The Long Hold | Solid

破壊的な変更として、createResource/batch/startTransitionなどのAPIが削除され、SolidStartは廃止されています。
createMemoでPromiseや非同期イテレーターを扱えるようになり、Loading/isPendingで読み込み状態を管理できます。
サーバ関数がコアに統合され、liveによるServer-Sent Eventsでの継続的なデータ受信に対応しています。
また、ReactiveScript/TSRXを実験的にサポートしています。

Chrome for Developersが、AIコーディングエージェント向けのModern Web Guidanceを提供しています。

  • Modern Web Guidance | Chrome for Developers

Modern Web Guidanceは、AIコーディングエージェント向けに、Web開発の実装指針やブラウザ互換性データを提供するスキル集です。
modern-web-guidance CLIで導入でき、AI Agentから利用できます。
CSSやWeb APIの活用、既存コードの移行、セキュリティやパフォーマンスの改善に関するガイドが含まれます。

Ladybirdのアルファ版がmacOSとLinux向けに公開されました。

  • Ladybird is now in alpha - Ladybird

Ladybirdは、既存エンジンのフォークではなく、独自に開発したエンジンを使うブラウザです。
アルファ版は自動更新に対応し、WebDriverによる自動テストとFirefox DevToolsプロトコルをサポートしています。

jQuery ReleaseNote library

jQuery 4.1.0と3.8.0リリース。
