JSer.info #781 - Cloudflare가 Deno 인수를 발표했다.

  • Deno is joining Cloudflare | Deno
  • The state of Deno after the Cloudflare announcement · Issue #37030 · denoland/deno

Deno 런타임은 1년간 버그 수정・보안 업데이트 진행한 이후, Deno 팀에 의한 개발이 종료된다.
Deno Deploy은 6개월 후에 종료, JSR은 Cloudflare로 이행되어 계승된다.
앞으로는 Workers과 Durable Objects 플랫폼에 주력, rusty_v8은 지속해서 지원하며 workerd으로 통합 진행이 예정되었다.

TanStack Start 1.0 출시되었다.

  • TanStack Start 1.0 is Stable | TanStack Blog

TanStack Start은, TanStack Router를 기반으로 하는 React/Solid 대상 풀스택 프레임워크이다.
SSR와 스트리밍, 자료형 있는 서버 함수 createServerFn, 실행 환경 째로 처리를 전환하는 createIsomorphicFn를 제공한다.

Bun 1.4.3 출시되었다.

  • Bun v1.4.3 | Bun Blog

TypeScript 자료형 체크하는 bun check가 추가되어, bun run --check/bun test --check/bun build --check에 대응한다.
또한, --disallow-code-generation-from-strings으로 문자열에서 생성 금지, bun build --compile --bytecode-order에 대응한다.

Panda CSS 2.0 출시되었다.

  • Panda CSS 2.0 | Panda CSS Blog - Panda CSS

Panda CSS 2.0에는, ESM만 가능해 Node.js 22 이상이 필요가 되었으며, hooks가 plugins으로 마이그레이션된다.
또한, 컴파일러가 Rust와 Oxc으로 재작성되어, panda lib와 designSystem으로 디자인 시스템 배포에 대응한다.
그 외로는, viewTransition()/firstThatWorks()/keyframes()/positionTry(), panda doctor/panda analyze/panda debug가 추가되었다.
