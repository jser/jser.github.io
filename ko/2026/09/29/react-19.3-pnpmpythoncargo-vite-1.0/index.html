  • Tweet

JSer.info #780 - React 19.3가 출시되었다.

  • React 19.3 – React

<ViewTransition>와 Fragment Refs가 Stable이 되었다.
react-dom에, use(browser())으로 컴포넌트를 브라우저에서만 렌더링하기 위한 browser()가 추가되어, Trusted Types API에 대응했다.
Server Components으로 <Context>를 직접 렌더링할 수 있게되어, onFullscreenChange/maskType 지원이 추가되었다.

pnpm 12.4, 12.6가 출시되었다.

  • pnpm 12.4 | pnpm
  • pnpm 12.6 | pnpm

pnpm 12.4에는, python.enabled/cargo.enabled로 Python/Cargo 의존 관계 관리에 대응했다.
Cargo 대응 배경에는, Rust로 작성된 pnpm 자체 의존관계를 pnpm로 해결하고 싶은 개발자의 의도가 있다.
또한, pnpm pipeline, trustPolicyExcludePrune, pnpm change check가 추가되었다.

pnpm 12.6에는, autoDedupe에 의한 의존 관계 중복 제거, pnpm add --save-types, Catalogs에서의 file:/link: 지원이 추가되었다.
그 외로, pnpm tasks status, pnpm cache prune --dry-run가 추가되었다.

Vite+ 1.0가 출시되었다.

  • Announcing Vite+ 1.0 | VoidZero

Beta부터는, GitLab CI/CD 대상 setup-vp, Homebrew와 Docker 이미지, vp hooks/vp staged가 추가되었다.
vp test와 vite-plus/test*가 Vitest 5.0.1으로 이행하여, CLI의 Node.js 지원 범위가 변경되었다.
oxlint/oxfmt 실행 파일 래퍼가 삭제되어, vp lint --lsp/vp fmt --lsp를 사용하는 형태로 변경되었다.
그리고, vp migrate에 의한 Vitest 5으로 이행, npm provenance 검증, vp add --offline/--frozen-lockfile 지원이 추가되었다.
