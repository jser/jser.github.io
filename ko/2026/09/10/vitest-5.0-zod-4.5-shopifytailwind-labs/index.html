2026-09-10: Vitest 5.0, Zod 4.5, Shopify가 Tailwind Labs 인수

2026年09月10日 Translator: rewrite0w0 Edit on GitHub See Revisions
  • Tweet

JSer.info #779 - Vitest 5.0가 출시됐다.

  • Vitest 5.0 is out! | Vitest

clearMocks가 기본적으로 유효, locator가 완전 일치해야 검색되도록 변경된다.
Benchmarking API가 재작성되어, Browser Mode의 browser.traceView, vi.when가 추가된다.
또한, vitest doctor, --repeats, coverage.autoAttachSubprocess 추가된다.

Zod 4.5가 출시됐다.

  • Zod 4.5

z.compile()에 의한 스키마 사전 컴파일, z.creditCard(), z.properties()가 추가된다.
z.deepPartial(), .exactPartial(), z.validate(), z.input()/z.output(), z.toZod<T>() 추가된다.
그 외로, z.iso.datetime()에서 초가 필수적이도록 변경, 문자열 길이를 Code Point로 세도록 변경, __proto__를 항상 제거하도록 변경.

Shopify가 Tailwind Labs 인수를 발표했다.

  • Tailwind Labs is joining Shopify - Tailwind CSS

Tailwind CSS 오픈소스 프로젝트는 MIT 라이센스 유지, Tailwind Labs 팀이 Shopify 지원을 받으며 개발 지속한다.
Tailwind Plus와 ui.sh는 기존 고객 접근 유지, 신규 등록 종료할 예정이다.
